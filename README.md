# ShareMeal 🍱

### A Full-Stack Food Donation and Redistribution Platform

ShareMeal is a MERN stack-based web application that connects food donors, NGOs, and volunteers to reduce food wastage and help people in need.

## Features
- User Registration and Login
- Role-based access for Donors, NGOs, and Volunteers
- Food Donation Management
- Donation Listing and Claiming
- Volunteer Pickup and Delivery Management
- Secure Authentication using JWT and Cookies

## Tech Stack
- Frontend: React.js, JavaScript, CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT, bcryptjs

## Installation and Setup

1. Clone the repository.
2. Install frontend and backend dependencies.
3. Configure environment variables.
4. Start the backend and frontend servers.

## Project Purpose

To reduce food waste by connecting food donors with NGOs and volunteers, ensuring surplus food reaches people who need it.
